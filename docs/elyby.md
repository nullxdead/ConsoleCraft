# Скины Ely.by

Опция «Использовать скины Ely.by» сохраняется отдельно в каждом игровом профиле и по умолчанию выключена. Интеграция предназначена для совместимых локальных/offline и демонстрационных запусков. Microsoft-профиль всегда использует официальную авторизацию и стандартные скины Minecraft; попытка внедрить Ely.by в такой сеанс отклоняется. Токен Microsoft никогда не передаётся Ely.by.

При включении Console Launcher получает публичный профиль скина по нику из документированного `https://skinsystem.ely.by/profile/{nickname}` и использует соответствующий публичный UUID для локального игрового профиля. Это не вход в Ely.by, не сессия сервера и не замена лицензии Minecraft. Пароли Ely.by лаунчер не запрашивает и не сохраняет.

Для игры загружается authlib-injector с официального сервера проекта, указанного в его README. Перед активацией проверяются опубликованная SHA-256, размер и структура JAR. Загрузка атомарная, повреждённый кеш не используется. Java-agent подключается к `https://authserver.ely.by/` только после явного включения опции. Анализ архива не исполняет его код.

Доступность скина/плаща зависит от наличия текстур Ely.by, версии Authlib/Minecraft и сервера. Плащ отображается только если сервис возвращает его для профиля; лаунчер не выдаёт плащи. Сервер может навязать собственные текстуры или не поддерживать сторонние системы. Работа на лицензионных серверах с локальным профилем не обещается; эта опция не обходит проверку серверной авторизации.

Источники: [Ely.by authlib-injector](https://docs.ely.by/en/authlib-injector.html), [публичная система скинов](https://docs.ely.by/en/skins-system.html), [официальный authlib-injector](https://github.com/yushijinhun/authlib-injector), [метаданные последней сборки](https://authlib-injector.yushi.moe/artifact/latest.json).
