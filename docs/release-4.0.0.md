# Console Launcher 4.0.0 — терминальный лаунчер

- Меню управляется стрелками и Enter; обычные CLI-команды сохранены.
- Установщики автоматически скачивают проверенную сборку и регистрируют команду в пользовательском PATH.
- Qt и графическая оболочка удалены. Профили, аккаунты, моды, миры и настройки остаются в существующем каталоге данных.

Windows x86_64, macOS arm64 и Linux x86_64. Для других архитектур доступны исходники с Python 3.11+. Команды установки и удаления — в README.
