# Игровые профили

Console Launcher хранит реестр профилей в `profiles.json` рядом с `config.json`. Каждый профиль имеет UUID, имя, версию Minecraft, тип и версию модлоадера, игровой каталог, RAM, Java, дополнительные аргументы, режим входа, настройку Ely.by и даты создания/запуска. Библиотеки и ресурсы Minecraft могут храниться в общем кеше; `mods`, `saves`, настройки игры и ресурсные наборы используют игровой каталог конкретного профиля.

Новые игровые каталоги по умолчанию создаются в `profiles/<UUID>/game`. Имена профилей не используются как пути. Профили с пересекающимися игровыми каталогами запрещены. Отдельный внешний абсолютный каталог можно выбрать при создании профиля. Для смены уже используемого каталога создайте отдельный профиль и перенесите проверенные данные — автоматического перемещения пользовательских миров нет.

При первом запуске версии 2 старые настройки преобразуются в схему 2; создаётся `config.v1.backup.json`. Профиль `Default` использует прежний каталог `minecraft`: существующие миры и моды остаются на месте. Идентификаторы приложений сохраняются в системном хранилище, когда оно доступно. Конфигурация и реестр сохраняются атомарно. Повреждённый JSON не сбрасывается молча.

Команда `profiles` предоставляет создание, просмотр, редактирование, переименование, копирование, выбор по умолчанию, импорт и экспорт. Полный синтаксис: `consolelauncher profiles --help` и справка соответствующей подкоманды.

Копирование переносит моды, настройки модов, resourcepacks, shaderpacks и параметры профиля в новый каталог с новым UUID. **Миры не копируются.** Экспорт создаёт переносимый ZIP с `profile.json` и разрешёнными игровыми файлами. Экспорт не включает миры, данные Microsoft, пути к Java/игровым каталогам и дополнительные аргументы запуска. Перед передачей архива другому человеку проверьте настройки модов: они могут содержать личные параметры самих модов.

Импорт проверяет все пути, размер архива, суммарный распакованный размер, размеры файлов, дубликаты, ссылки и CRC. Файлы сначала потоково читаются во временный каталог. Используется новый UUID и новый управляемый игровой каталог; архив не может задать абсолютный путь на компьютере. Символические ссылки, `..`, обратные слеши, неизвестные корневые файлы и аргументы запуска из чужого архива запрещены. По умолчанию допустимо до 4096 файлов, 256 МБ на файл и 1 ГБ данных.

Удаление записи профиля требует подтверждения и по умолчанию **сохраняет все игровые файлы и миры**. Удаление игрового каталога требует отдельного подтверждения удаления миров. Старые и внешние каталоги автоматически не удаляются даже с подтверждением. Это позволяет восстановить запись профиля или вручную сохранить нужные данные.

Дополнительные аргументы передаются как список строк без shell. Подмена аргументов авторизации, выбранного игрового каталога и внедрение произвольного Java-агента через профиль запрещены. Интеграция Ely.by настраивается отдельно; для аккаунтов Microsoft стандартная авторизация остаётся режимом по умолчанию.
