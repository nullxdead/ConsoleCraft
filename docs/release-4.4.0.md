# ConsoleLauncher 4.4.0

- Вход Microsoft открывает браузер и возвращает в лаунчер после подтверждения.
- Обновлены настройки приложений и исправлены связанные ошибки.
- Каталог дополнений, игровые профили и Discord Rich Presence сохранены.

Для входа Microsoft приложение должно поддерживать личные аккаунты и адрес возврата `http://localhost`. На новом устройстве необходимо сначала настроить идентификаторы приложений; существующие настройки переносятся из предыдущей версии при доступном системном хранилище.
