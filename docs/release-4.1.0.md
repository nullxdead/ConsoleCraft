# Console Launcher 4.1.0 — отмена загрузки и возврат в меню

- Нажмите Ctrl+C во время установки или загрузки: лаунчер остановит работу и вернётся в меню. Прямые CLI-команды завершаются с кодом 130.
- В подменю появился пункт «На главный экран»; при вводе текста и подтверждениях можно нажать Ctrl+C.
- Скачиваемые файлы сначала записываются во временный файл, поэтому незавершённая загрузка не заменит готовый файл. Повторная установка использует уже скачанные компоненты.
- Активные сетевые соединения могут завершаться до установленного таймаута.
