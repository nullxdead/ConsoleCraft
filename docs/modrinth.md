# Modrinth и менеджер модов

Console Launcher использует официальный API v2 `https://api.modrinth.com/v2`. Поиск фильтруется по Minecraft и модлоадеру; описание проекта содержит авторов, а список версий позволяет выбрать точный релиз. Обязательные зависимости разрешаются до установки. Неизвестные внешние зависимости и противоречивые версии отклоняются.

Загрузки допускаются только с HTTPS `cdn.modrinth.com`, без перенаправлений. Размер ограничен 512 МБ (можно уменьшить), SHA-512 или SHA-1 сверяются с API, JAR проверяется перед копированием. Все зависимости сначала загружаются во временный каталог; ошибки до установки не меняют профиль. Ошибки HTTP 429 сообщают время повторного запроса. Нужен интернет; токен Modrinth для публичного каталога не требуется.

Локальные `.jar` можно установить, искать, отключать (`.jar.disabled`), включать и удалять с подтверждением. Моды каждого профиля находятся только в его `mods`. Проверка метаданных Fabric, Quilt, Forge и NeoForge не запускает Java-код и не извлекает архивы. Подозрительные пути, ссылки, шифрование, слишком большие метаданные, ZIP-бомбы и повреждённые архивы отклоняются.

Диагностика обнаруживает повторяющиеся mod ID, известные несовместимости, обязательные отсутствующие зависимости и диапазоны версий. Поддерживаются обычные числовые диапазоны Fabric/Quilt и Maven; неизвестный синтаксис обозначается как непроверенный, а не совместимый. Совместимость Fabric-мода с Quilt нельзя гарантировать по одному названию загрузчика.

Обновления определяются официальным `POST /version_file/{hash}/update`. Замена файлов требует явного подтверждения. Исходный файл сохраняется на время операции и восстанавливается при ошибке. Обновление мира не выполняется.

**Моды могут выполнять произвольный код при запуске Minecraft. Устанавливайте их только из доверенных источников.** Проверка хеша подтверждает целостность, но не безопасность кода; метаданные не описывают все возможные конфликты.

Официальные источники: [API overview](https://docs.modrinth.com/api/), [поиск](https://docs.modrinth.com/api/operations/searchprojects/), [версии проекта](https://docs.modrinth.com/api/operations/getprojectversions/), [обновление по хешу](https://docs.modrinth.com/api/operations/getlatestversionfromhash/).
