# ConsoleLauncher 4.3.0

- Фиолетовый фон со сменой оттенков, в том числе в классической консоли Windows. Цвета восстанавливаются при выходе.
- Каталог Modrinth теперь позволяет находить и устанавливать моды, модпаки, шейдеры и ресурс-паки с помощью стрелок.
- Модпак создаёт отдельный профиль; Minecraft и модлоадер скачиваются при запуске игры. Необязательные файлы модпака пропускаются.
- Discord Rich Presence для всех профилей показывает лаунчер и версию игры, когда открыт настольный Discord. Его можно отключить в настройках.
