# Console Launcher 4.2.0

- Фиолетовый фон и обновлённое оформление в поддерживаемых терминалах; после выхода возвращается цветовая схема терминала по умолчанию.
- Некорректное значение настройки больше не закрывает лаунчер. Параметры меню получили понятные названия.
- Исправлена проверка обновлений; запустить её можно из главного меню.
- Обновлены имена создателей и условия использования новых изменений. Права на версии 4.1.0 и ранее и лицензии сторонних компонентов сохранены.

Для отключения изменения фона используйте `CONSOLECRAFT_NO_BACKGROUND=1` или `NO_COLOR`. Доступны сборки для Windows x64, macOS Apple Silicon и Linux x64; на других архитектурах можно запустить исходники.
