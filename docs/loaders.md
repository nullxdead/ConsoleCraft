# Fabric, Forge, NeoForge и Quilt

Console Launcher использует документированный единый API `minecraft_launcher_lib.mod_loader` версии 8: каталог поддерживаемых Minecraft, версии загрузчика, проверка выбранной пары и официальный установщик. Версия игры и версия загрузчика выбираются раздельно; неподдерживаемая пара отклоняется до установки. Vanilla-клиент, библиотеки и Java хранятся в общем техническом каталоге; моды, миры и настройки — в каталоге выбранного профиля.

Установка считается успешной только после появления ожидаемого ID версии, построения classpath и проверки всех его файлов. Проверяются SHA-1 клиентского JAR, библиотек и ресурсов, когда официальные метаданные публикуют эти суммы. Файлы, созданные процессорами установщика без опубликованных хешей, проверяются на наличие и ненулевой размер. Полная семантическая совместимость произвольных модов этим не доказывается.

Восстановление повторяет официальный установщик. Повреждённые технические файлы предварительно переносятся в `.consolecraft-quarantine` внутри общего каталога Minecraft; пользовательские миры и моды не затрагиваются. Установка Forge/NeoForge/Fabric/Quilt запускает официальный Java-установщик. Анализ модов никогда не выполняет их JAR.

HTTP-запросы установщика ограничены тайм-аутом, процессы установщика — 15 минутами; запросы каталога используют те же ограничения. До выполнения официального installer JAR его поток сверяется с SHA-1 sidecar из того же официального Maven-репозитория; отсутствие или несовпадение суммы отменяет запуск. Скорость зависит от серверов проектов. Для старых версий, ARM64 и Apple Silicon доступность Java и нативных библиотек может отличаться; несовпадение Java явно сообщается.

Официальные источники: [единый API библиотеки](https://minecraft-launcher-lib.readthedocs.io/en/stable/modules/mod_loader.html), [Fabric CLI](https://wiki.fabricmc.net/install#cli_installation), [Forge](https://files.minecraftforge.net/), [NeoForge](https://neoforged.net/), [Quilt](https://quiltmc.org/en/install/).
